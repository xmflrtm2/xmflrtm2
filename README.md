## 박한울 | UE5 C++ 게임플레이·시뮬레이션 프로그래머

Unreal Engine 5와 C++로 게임플레이 시스템을 만듭니다.
지금은 항공 정비훈련 VR 시뮬레이터 개발팀에서 훈련 콘텐츠 개발, 정비 절차 QA, 빌드·안정성 문제 해결을 맡고 있습니다.

### 대표 작업

| 프로젝트 | 내용 | 링크 |
|---|---|---|
| **조선협객전설** (UE5 C++ 탑다운 액션 로그라이크, 3인 팀 리드) | Actor Component 기반 베이스 프레임워크, 내적 기반 전투 판정·대시·피격 반응, StateTree AI와 런타임 스폰 문제 해결, 게임 흐름(난이도·데이터 보존·결과창) | [코드](https://github.com/xmflrtm2/LegendOf502-Gameplay), [시연 영상](https://youtu.be/06xDSLaac4Y) |
| **Auto UE Builder** (C# WinForms) | UE5 Generate, Build, 패키징·압축·캐시 정리를 프리셋 기반 원클릭으로 처리, 잠금 파일 기반 작업 대기열 | [AutoGenerate](https://github.com/xmflrtm2/AutoGenerate) |
| **Clistock** (Python) | 한국투자증권 OpenAPI 자동매매·백테스트 도구. 규칙 기반 매매 + AI 보조, 견고성 분석·워크포워드 검증 | [Clistock](https://github.com/xmflrtm2/Clistock) |

### 기술

- **Unreal Engine 5, C++, Blueprint**: 게임플레이 프레임워크(GameMode, GameInstance, PlayerController), Actor Component 설계, StateTree, EQS, Enhanced Input, AnimMontage, AnimNotify, UMG, 패키징
- **VR**: Meta Quest 3, 핸드트래킹 인터랙션, VR UI
- **도구·자동화**: C#, Python, PowerShell, Git, Git LFS, Claude Code 기반 QA 자동화
